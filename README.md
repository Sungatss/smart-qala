# Smart Qala • Семей (Smart City Hackathon 2026)

**Smart Qala** — открытая цифровая платформа для прямого взаимодействия жителей города Семей и муниципальных служб (ЖКХ, отдел пассажирского транспорта, отдел благоустройства, управление экологии).

> **Формула платформы:**
> **Сообщить → Понять → Направить → Решить → Показать результат**

---

## 🏛️ Архитектурные принципы и Anti-Vibe-Coding
- **Институциональный дизайн**: Нейтральная палитра (`#F9FAFB`), строгие границы (`#E5E7EB`), контрастный сланец (`#111827`), официальные темные кнопки (`#0F172A`).
- **Никаких фиолетовых градиентов, глассморфизма или неоновых подсветок**.
- **Никаких пилюлевидных кнопок**: максимальный радиус скругления 8px (`rounded-md` / `rounded-lg`).
- **Монохромная векторная иконография**: исключительно `lucide-react`.
- **Без выдуманных счетчиков, фейковых отзывов и тире в текстах интерфейса**.
- **Маркировка данных**: Все демо-записи явно помечены как `ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ / СЕМЕЙ`.

## 🤖 Модуль ИИ и Graceful Fallback (`src/lib/ai-service.ts`)
- **Основной режим**: Вызывает `@google/genai` (модель `gemini-2.5-flash`) с JSON schema.
  - *Правило промпта*: Никогда не придумывать факты, сохранять конкретику, чистить эмоции и ненормативную лексику, классифицировать ведомство и обосновывать приоритет.
- **Отказоустойчивый режим (Fallback)**: Детерминированный движок на регулярных выражениях и правилах, срабатывающий автоматически при отсутствии API-ключа или сетевых сбоях.

## 🛠️ Запуск проекта

```bash
# Переход в директорию приложения
cd smart-qala

# Установка зависимостей (уже установлены)
npm install

# (Опционально) Установка ключа Gemini в .env.local
echo "GEMINI_API_KEY=your_key_here" > .env.local

# Запуск dev-сервера
npm run dev

# Сборка и запуск продакшн-версии
npm run build
npm run start
```
Сервис доступен по адресу: `http://localhost:3000`.
